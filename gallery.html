Colour

Neutrals are the F5DS N-ramp. Two are derived because F5DS’s own published values fail WCAG AA: secondary text on the page background measures 4.25:1, and the documented icon colour manages 2.42:1 on white. Run scripts/check-contrast.py for the full table.

Button

Exactly one Primary per group, 20px between buttons, never truncates, always elevation L0. Primary uses --green-text rather than --green: white on #009639 is 3.87:1 and fails AA.

Tag and status

Tags are the only elements permitted the pill radius. A status dot is never rendered without its label — Emerald and Amber measure 2.02:1 and 1.60:1 on white and cannot reach the 3:1 non-text bar at any usable saturation, so the label carries the meaning and the hue only reinforces it.
