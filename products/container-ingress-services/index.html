BIG-IP Container Ingress Services

CIS is a controller that runs inside your cluster, watches the Kubernetes API, and reprograms an external BIG-IP so its configuration always matches what is running. It is how a BIG-IP you already operate becomes a Kubernetes ingress tier — without asking your platform teams to learn its configuration model.

Apache 2.0 v2.20.4 Requires a BIG-IP

The GitHub repository is being archived

As of April 2026 the F5Networks/k8s-bigip-ctlr repository is no longer monitored, and GitHub issues are not watched by F5 support. The product is not retired — v2.20.4 shipped in June 2026, releases continue through the Red Hat Container Registry, Docker Hub and Quay, and support goes to F5 Technical Support. No end-of-support notice has been published for the product itself.

What it does

Programs BIG-IP from Kubernetes

Watches Services, Endpoints, Nodes and its own resources through client-go informers, and applies changes to the BIG-IP as AS3 declarations.

Six custom resources

VirtualServer, TLSProfile, TransportServer, ExternalDNS, IngressLink and Policy — an alternative to spreading configuration across annotations.

Every resource model

Kubernetes Ingress, OpenShift Routes including NextGenRoute, ConfigMap declarations, and Service type LoadBalancer with a load balancer class.

Four pool member modes

NodePort, ClusterIP, NodePortLocal and Auto, so the BIG-IP can reach pods whichever way your cluster networking is arranged.

CNI integration

Static routing, Calico, Cilium with VXLAN or Geneve, Antrea including NodePortLocal, and VXLAN tunnels for OpenShiftSDN.

Multi-cluster

Expose applications spread across several clusters behind a single BIG-IP virtual server, in standalone or HA topologies.

Getting the controller

CIS needs a BIG-IP to talk to, credentials for it, and a set of controller flags that depend on which resource model you are using, so a one-line install would be misleading. The image reference is below; the installation guide covers Helm, manifests and the OpenShift Operator.

# Pull the controller image; see the install guide for Helm values docker pull docker.io/f5networks/k8s-bigip-ctlr:2.20.4 # Also published on Quay and the Red Hat Container Registry
